A standalone GitHub-compatible git forge in one Node 22 process: git smart HTTP (protocol v0 and v2), REST v3, GraphQL, and MCP, all served from its own in-memory store. No UI, no git binary, no database, no model calls — deterministic from the trial seed and opening time.

## Run it

```sh
node --experimental-strip-types main.ts
```
